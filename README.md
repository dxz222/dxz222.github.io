# Xinzhe Dai — Personal Website

Personal academic website for Xinzhe Dai, built with Astro and based on the Astro Scholar theme.

## Local development

```sh
npm install
npm run dev
```

The local site is available at `http://localhost:4321/`.

## Build

```sh
npm run build
```

The production site is generated in `dist/`.

## Deployment

Pushing the `main` branch triggers the GitHub Pages workflow in `.github/workflows/deploy.yml`.

Live site: <https://dxz222.github.io/>

## Theme

Based on [Astro Scholar](https://github.com/shravanngoswamii/astro-scholar) by Shravan Goswami.
